商品管理系统使用说明

【一、系统简介】
本系统是面向中小型电商与零售企业的 AI 智能商品管理系统，采用前后端分离架构。
后端基于 FastAPI + MySQL，AI 能力由 RAG 知识库、商品 Agent 与 MCP 工具链共同提供。
系统包含商品、分类、库存、订单、客户、数据分析六大业务模块，以及 AI 助手、知识库、
商品 Agent、MCP 工具中心、Agent 调用链等智能化模块。

【二、功能模块说明】
1. 工作台：展示商品总数、订单总数、销售额、库存总量、客户数量等核心指标，
   并提供销售趋势、分类销售占比、热销商品排名与库存分析图表。
2. 商品管理：商品的新增、修改、删除、搜索、上下架，支持按分类与状态筛选。
3. 商品分类：支持两级分类（如「手机 → iPhone」），可维护排序与启用状态。
4. 库存管理：查看库存、入库、出库、库存预警与缺货查询。
5. 订单管理：创建订单、查询订单、修改订单状态、取消订单。
   订单状态流转顺序为：待付款 → 已付款 → 待发货 → 已发货 → 已完成。
6. 客户管理：维护客户信息、消费次数、消费金额、最近购买时间与客户等级。
7. 数据分析：统计商品总数、订单总数、销售额、库存量、客户数量，
   并输出销售趋势、分类销售占比、商品排名等可视化图表。
8. AI 助手：基于 RAG 知识库回答商品、售后、库存、系统相关的自然语言问题。
9. AI 知识库：管理知识文档，支持上传、向量化、检索测试与索引重建。
10. 商品 Agent：理解用户的业务问题，自动调用工具查询数据库并给出分析与建议。
11. MCP 工具中心：展示 Agent 可调用的全部工具，支持手动传参调用。
12. Agent 调用链：记录每次 Agent 执行的完整链路，便于排查与演示。

【三、常见操作】
Q：如何新增商品？
A：进入「商品管理」页面，点击「新增商品」，填写名称、分类、售价、库存等信息后保存。
Q：如何查询库存不足的商品？
A：进入「库存管理」页面查看「库存预警」区域，或在 AI 助手中提问“哪些商品快没货了”。
Q：订单状态如何变更？
A：在订单列表中点击「修改状态」，系统只允许按合法顺序流转，不能跳级。
Q：知识库怎么用？
A：把商品资料、售后政策等文本文件放入知识库并点击「重建索引」，
之后在 AI 助手中提问即可获得基于知识库的回答。

【四、技术说明】
前端：原生 HTML + CSS + JavaScript + ECharts；
后端：FastAPI + SQLAlchemy + MySQL；
AI：OpenAI 兼容大模型接口 + Chroma 向量数据库 + MCP 工具协议。
